About predictions
This page uses a previously trained model to create new predictions. Models can be compared in the Evaluate tab to get an idea of how it performs on unknown data. The trained model only has information available at the time of training. For each model selected, the sidebar loads info on what range of dates the model was trained on and what dates are available for validation and prediction.
Validation uses waterfall + consumption info that is new to the model to gauge prediction accuracy. Validation must be performed on weeks where both data is known.
Prediction is automatically performed on all cases where future data is not known. If more targeted predictions are needed, uncheck "Predict on all available future waterfall data" and instead select the range of weeks to use; predictions will only be made for those weeks.
Extend Prediction(s) enables a lookahead greater than the waterfall currently forecasts. They can be extended by as many weeks as desired, but behavior may be unstable.
