Loading New Data
Loaded data is automatically parsed into the processed database. Files must follow the naming convention YYYYwkWW.prn (e.g. 2026wk01.prn, 2024wk52.prn). Files are deposited under data/<plant>/raw/<data type>/ then loaded into a processed database.
Currently, no strategies exist for item to item data management; still TODO: allow overwrite of data - for now, what you upload is permanently in the system - exerise caution!
Cost Data
Cost files are fixed-width price-list reports in the same layout as the diamond reports: a report header, a column-header line, a ---- ruler that sets the column widths, then one row per price-list line. Only Item Number, Start (MM/DD/YY) and the first break amount are kept, and only the most recent Start per part.
Files are deposited under data/<plant>/Cost/; every file in that folder is re-read on each load.
