🏠 Forecast Tool

A supply-chain demand-forecasting toolkit for loading raw data, training predictive models, generating predictions, and evaluating model performance.

📂
Load
Upload raw .prn / .txt files (Consumption, Waterfall, Cost) and ingest them into the local SQLite database.
📊
Reports
Generate order-accuracy error charts and data-coverage heatmaps for any plant and date range.
🔧
Train
Fit a new forecast model (HGB, Random Forest, or Neural Net) on a configurable training window with optional holdout evaluation.
🗂️
Models
Browse all saved model bundles — inspect training span, feature count, and holdout scores (R², MAE, MSE) at a glance.
🔮
Predict
Run a saved model against current waterfall data to produce part-level quantity forecasts.
📈
Evaluate
View the holdout-set performance report for any trained model — scatter plots and error distributions vs. the naïve baseline.
