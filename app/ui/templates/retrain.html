Model parameters

The model parameters are settings that can improve or worsen predictions. It's hard to know how parameters will directly impact predictions

  • Model type dictates how the ML model learns. An overview of model types is visible below: generally, HGB is a strong balance of complexity and accuracy.
  • Order Date Range is the span over which the model "learns." Attempting to predict within this range will result in inflated performance. This should be set to have a large enough representative range.
  • Validation Weeks Withhold a set number of weeks from , we can validate model performance. Ordering predictions and consumption is then saved with the model so we have an immediate indication about how well the model works on never before seen data.
  • Excluded weeks are left out of both training and validation scoring. The model saves the exact list of weeks it trained on, and Retrain refills these fields.
